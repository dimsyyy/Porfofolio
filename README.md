# Portfolio — Dimas Yuda Pratama

Website portfolio pribadi Dimas Yuda Pratama yang menampilkan profil, pendidikan, pengalaman organisasi, keahlian, serta karya di bidang pengembangan web dan visual.

Mengusung tampilan dark mode yang responsif, dengan navigasi smooth scrolling dan filter interaktif untuk menjelajahi keahlian serta proyek. Tersedia juga tautan CV dan media sosial untuk terhubung.
